# AIS Execution Engine — Core Runtime

> **Version**: 0.1.0 (Foundation Skeleton)
> **Status**: Development — infrastructure only, no business logic
> **Conforms to**: CON-001.000, ARC-001.001, DOM-001.000, DOM-002.000, ADR-001..014

## Overview

The AIS Execution Engine is the adaptive intelligence layer between the security platform and its human operators. It transforms tools into a proactive companion that understands context, predicts intent, and delivers assistance.

This foundation provides the **structural skeleton** — interfaces, types, lifecycle, and event infrastructure — onto which business logic will be added in subsequent tasks (AIS-003B+).

## Adding Components

### Register a New Service

```typescript
import { ExecutionEngine } from './core/index.js';
import type { Service } from './core/services/service.js';

const myService: Service = {
  name: 'my-module',
  initialize: async () => { /* setup */ },
  start: async () => { /* begin work */ },
  stop: async () => { /* graceful stop */ },
  shutdown: async () => { /* cleanup */ },
};

const engine = new ExecutionEngine();
engine.services.register(myService);
```

### Subscribe to Events

```typescript
engine.eventBus.subscribe('UserActionRecorded', async (envelope) => {
  console.log('Action recorded:', envelope.payload);
});
```

### Add a New Domain Entity

1. Create `src/core/domain/entities/my-entity.ts` extending `EntityBase`
2. Define state enum for FSM
3. Export from `src/core/domain/entities/index.ts`
4. Add to `src/core/domain/index.ts` barrel

### Add a New Domain Event

1. Add typed interface to `src/core/domain/events/events.ts`
2. Add to `DomainEvent` union type
3. Update aggregate to emit the event

## Engine Lifecycle

```
initialize() → start() → [execute()] → stop() → shutdown()
```

- **initialize()**: Sets up infrastructure, validates configuration
- **start()**: Starts all registered services, opens event bus
- **execute()**: Main execution loop (placeholder — AIS-003B+)
- **stop()**: Gracefully stops all services
- **shutdown()**: Full teardown, releases resources

## Limitations (Current Foundation)

- No business logic implemented
- No LLM/Scanner/Storage provider implementations
- No memory persistence
- No plugin loading
- No UI/CLI interfaces
- `execute()` is a placeholder returning empty result
