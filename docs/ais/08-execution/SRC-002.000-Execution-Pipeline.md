## 1 — Назначение

Справочник описывает файловую структуру подсистемы Execution Pipeline (`src/core/pipeline/`), конечного автомата (`src/core/fsm/`) и трассировщика (`src/core/trace/`). Все типы спроектированы в соответствии с DDD (ADR-014), модульным монолитом (ADR-001) и событийно-ориентированной архитектурой (ADR-002). Идентификаторы брендированы для типобезопасности, артефакты иммутабельны.

## 3 — Интерфейсы конвейера

| # | Интерфейс | Методы | Описание |
|---|-----------|--------|----------|
| 1 | Planner | buildPlan(goal, vars?) → Plan | Производит Plan из Goal |
| 2 | RetryPolicy | decide(attempt, error) → RetryDecision | Стратегия повторных попыток |
| 3 | RecoveryPolicy | decide(error, attempt, token?) → RecoveryDecision | Восстановление: retry/abort/escalate |
| 4 | TaskHandler | execute(task, ctx) → TaskResult | Обработчик типа задач |
| 5 | StateMachine\<S\> | transition(to), canTransition(to), isTerminal | Конечный автомат |
| 6 | CancellationToken | cancel(reason?), onCancel(cb) | Токен отмены |

## 5 — Иерархия ошибок

```
ExecutionError (code, retryable, toTaskError())
├── PlanningError (PLANNING_ERROR, not retryable)
├── TaskExecutionError (TASK_EXECUTION_ERROR, taskId, stepId, attempt)
├── TaskTimeoutError (TASK_TIMEOUT, retryable)
├── TaskCancelledError (TASK_CANCELLED)
├── SchedulerError (SCHEDULER_ERROR)
├── InvalidTransitionError (INVALID_TRANSITION, fromState, toState)
├── PipelineAbortedError (PIPELINE_ABORTED, failedTaskId?)
└── EscalationError (ESCALATION, originalError)
```

---

## 6 — FSM Execution Pipeline

```
Idle → Planning → Ready → Running → Completed (terminal)
                              → Failed (terminal)
                              → Cancelled (terminal)
Planning → Failed | Cancelled
Ready → Cancelled
```
