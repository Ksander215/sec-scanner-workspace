## 1. Module Structure

The Knowledge Runtime is implemented in `src/core/knowledge/` with the following files:

| File | Purpose |
|------|--------|
| types.ts | Domain types: KnowledgeItem, KnowledgeDocument, KnowledgeFragment, KnowledgeCollection, KnowledgeNamespace, KnowledgeVersion, KnowledgeRelation, KnowledgeMetadata, KnowledgeSource, plus enums, branded IDs, serializable counterparts |
| errors.ts | Error hierarchy: KnowledgeError base + 15 specific error classes |
| events.ts | 14 domain events for Event Bus integration (ADR-002) |
| storage.ts | 3 storage adapters: InMemoryKnowledgeStorageAdapter, FileKnowledgeStorageAdapter (ADR-004), SnapshotKnowledgeStorageAdapter |
| knowledge-index.ts | KnowledgeIndexRuntime — 5 index types (key, namespace, tag, source, timestamp) with auto-rebuild |
| retrieval.ts | KnowledgeRetrievalRuntime — search, filter, sort, paginate, query |
| knowledge-graph.ts | KnowledgeGraph — 8 relation types, cycle detection, BFS pathfinding, graph validation |
| versioning.ts | KnowledgeVersionManager — immutable revisions, rollback, lineage, history |
| validation.ts | KnowledgeValidator — 7 validation methods (namespace isolation, duplicates, broken refs, cycles, versions, graph consistency) |
| knowledge-runtime.ts | KnowledgeRuntime — main orchestrator integrating all subsystems |
| index.ts | Barrel exports for the entire module |

## 2. Component Description

### KnowledgeRuntime
The main orchestrator. Manages namespaces, items (CRUD), relations, versions, indexes, and validation. Publishes domain events via Event Bus. Enforces namespace isolation.

### KnowledgeIndexRuntime
Manages in-memory indexes for fast lookup. Supports 5 index types. Items are automatically indexed on create/update. Indexes can be rebuilt from scratch.

### KnowledgeGraph
Directed graph of knowledge relations. Supports 8 relation types. Cycle detection for Parent/Child/Dependency/DerivedFrom. BFS-based pathfinding.

### KnowledgeVersionManager
Immutable revision management. Each content update creates a new version. Supports rollback to any revision (creates a new version with old content). Max revision limit per item.

### KnowledgeValidator
Validates knowledge store consistency across 6 dimensions. Returns KnowledgeValidationResult with issues array.

### KnowledgeRetrievalRuntime
Stateless retrieval engine. Supports search, filtering (11 criteria), sorting (5 fields), pagination, and combined queries.

## 3. Public API

List the key interfaces and methods of KnowledgeRuntime:
- Namespace: createNamespace, deleteNamespace, getNamespace, listNamespaces
- Items: createItem, getItem, updateItem, deleteItem, listItems, setItemState
- Retrieval: search, query, getById, getByNamespace, getByTags, getBySource
- Graph: addRelation, removeRelation, getRelations, getRelatedItems, hasPath, getShortestPath, detectCycles
- Versioning: getVersion, getLatestVersion, getVersions, rollback
- Indexing: rebuildIndex, rebuildAllIndexes, getIndexStats
- Validation: validate
- Isolation: enforceNamespaceIsolation
- Lifecycle: dispose, getStats

## 4. Dependencies
