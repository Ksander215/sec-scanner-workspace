## 1. Purpose

Experience Runtime — система долгосрочной адаптации платформы под конкретного пользователя.

Это не память. Это не профиль. Это слой, который постепенно формирует цифровую модель взаимодействия пользователя с системой.

## 5. Integration Contracts

Experience Runtime integrates through contracts (no direct dependencies):

- ICognitiveRuntimeAdapter — intent and conversation context
- IIdentityRuntimeAdapter — user hashing and verification
- IMemoryRuntimeAdapter — memory provenance
- IKnowledgeRuntimeAdapter — domain context
- IWorkflowRuntimeAdapter — workflow data for recommendations
- ICapabilityRuntimeAdapter — capability data for recommendations

## 6. Principles

- Never modifies data in other Runtimes directly
- Works only through contracts
- All conclusions are probabilistic and explainable
- Stores provenance of every observation
- Makes no unjustified assumptions
- All adaptations are reversible and explainable
