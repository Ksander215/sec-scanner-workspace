## Purpose

We are researching how people understand software system architecture when given different types of support tools. This study compares independent code exploration with an AI-assisted architecture exploration tool.

> We are investigating **how people understand a system's architecture with different support methods** — not evaluating you as a person.

---

## What You Will Be Asked To Do

1. **Explore** an unfamiliar TypeScript codebase (`src/core/` directory, ~393 files, ~73k LOC)
2. **Answer** an architecture question based on your independent exploration (45 min timebox)
3. **Use** an AI-assisted architecture tool (AIS) to answer the same question
4. **Verify** the AI's claims by checking the actual source code
5. **Answer** follow-up questions about your experience

Total estimated time: **90–120 minutes**

---

## What We Record

- Your architecture answers (baseline and AIS-assisted)
