# Wave 1 — Recruitment Package

## Overview

This directory contains all materials for recruiting participants for AIS MVP Validation Wave 1.

## Objective

Recruit 5–8 real participants who are software professionals with experience reading and analyzing unfamiliar codebases.

## Target Profiles

| # | Role | Minimum Experience |
|---|---|---|
| 1 | Software Developer | 2+ years |
| 2 | Senior Developer | 5+ years |
| 3 | Tech Lead | 3+ years |
| 4 | Software Architect | 5+ years |
| 5 | Security Engineer | 3+ years |

Not all profiles need to be represented. The key requirement is the ability to independently investigate an unfamiliar repository.

## Recruitment Rules

1. **Neutral framing** — do not reveal the hypothesis (§10)
2. **No expectation bias** — do not suggest AIS will help
3. **Anonymous IDs** — use P001–P008, never real names in evidence
4. **Separate PII** — personal data stored separately from technical results
5. **Inclusion/exclusion criteria** — follow screening flow strictly
6. **Conflict check** — reject anyone who authored the validation scenario
