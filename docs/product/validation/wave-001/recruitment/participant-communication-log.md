## Communication Rules

1. **Log everything** — every email, message, conversation about the study
2. **No PII in technical records** — this log may contain names/contacts but keep separate from evidence ledgers
3. **Record timing** — when was the candidate first contacted? When did they respond?
4. **Record refusals** — if someone declines, log it (without pressuring)
5. **Record reasons** — if a candidate shares why they decline, note it (for recruitment optimization)
