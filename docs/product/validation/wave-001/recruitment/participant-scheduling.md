## Scheduling Rules

1. **No back-to-back sessions** — minimum 30-minute gap between sessions for observer reset
2. **Same observer preferred** — for consistency in observation quality
3. **Same environment preferred** — all sessions should use the same AIS deployment
4. **Rescheduling** — allowed; log in communication-log.md
5. **Cancellations** — log reason; attempt to fill slot
6. **No-show** — mark as cancelled; do not invent data

---

## Session Day Checklist

Before each session, verify:

- [ ] AIS is running at frozen version (`ab42c7a`)
- [ ] Repository is accessible (`src/core/`)
- [ ] Participant has confirmed attendance
- [ ] Consent form is ready (printed or digital)
- [ ] Briefing script is ready
- [ ] Timer/stopwatch available
- [ ] Recording mechanism ready (notes or audio)
- [ ] Evidence ledger template ready
- [ ] Observer has re-read the protocol
- [ ] No code changes since last session

---

## Environment Setup

### Online Session
- Screen sharing for observation (participant shares their screen)
- Observer can see file navigation but does NOT control it
- Audio recording if participant consents

### In-Person Session
- Participant uses their own laptop or provided workstation
- Observer sits to the side — does not look at screen over participant's shoulder
- Observer takes notes on separate device
