## 2. Overview

The Personal Intelligence Capability Pack is the user-facing intelligence layer that transforms raw platform data (goals, decisions, constraints, habits, conversations, knowledge) into actionable daily briefs, structured reflections, multi-stage recommendations, and a unified personal dashboard.

Without the Personal Intelligence Pack, platform runtimes collect data but provide no synthesis or user-facing intelligence. With the Pack, every interaction contributes to a growing personal intelligence model that surfaces constraints, prioritizes goals, and delivers recommendations through the mandatory 6-stage recommendation chain defined in GOV-008.000 §6.1.

The Pack is the mechanism through which the platform becomes personally intelligent.

### 2.1 Mandate

- Every recommendation must pass through all 6 stages of the recommendation chain (Understanding → Value → Constraint → Optimization → Explanation → Recommendation).
- Constraint detection follows The Goal (TOC) philosophy per PHI-003.000: Systemic → Major → Moderate → Minor severity, with lifecycle management (Detected → Analyzed → ActionPlan → Exploiting → Elevated → Resolved).
- All value assessments reference the 8 value dimensions defined in PHI-002.000 (VD-001..VD-008).
- The Pack integrates with 9 platform runtimes exclusively through contracts (AL-002: Boundary by Contract). It never imports concrete implementations.
- Every subsystem emits domain events classified per INV-012 (No domain event without a classification).

### 2.2 Design Principles

1. **Contract-Boundary** — The Pack defines 9 runtime contracts and depends only on these interfaces. Concrete runtimes are injected at construction time. The Pack never imports from any runtime module directly.
2. **Event-Driven** — All mutations emit domain events (29 event types). Subscribers are isolated: a failing handler never blocks the publisher.
3. **Immutable** — Every returned value object is frozen via `Object.freeze`. All interfaces use `readonly` arrays and properties.
4. **Branded Types** — 13 branded identifier types prevent accidental ID mixing between subsystems.
5. **Orchestrator Pattern** — The `PersonalIntelligencePackRuntime` wires 13 domain subsystems + 2 infrastructure subsystems (Metrics, Trace) and provides the single entry point for initialization, First Intelligence, and disposal.

### 3.2 Subsystem Responsibilities

The Personal Intelligence Pack comprises **15 subsystems**, each with a single responsibility:

1. **Daily Brief Generator** — Generates structured daily briefs (Morning, Midday, Evening, Weekly) containing priorities, events, incomplete tasks, recommendations, risks, bottlenecks, and optimizations. Aggregates data from workflow, personal, cognitive, and recommendation contracts.
2. **Reflection Engine** — Generates structured reflections (Daily, Weekly, Monthly) with accomplishments, lessons learned, sentiment analysis, and scoring. Evicts old reflections based on configurable history limit.
3. **Goal Planner** — Manages a 6-level goal hierarchy (Vision → Goals → Projects → Milestones → Tasks → Actions) with lifecycle status transitions, parent-child relationships, and cycle detection.
4. **Decision Advisor** — Supports structured decision analysis with multiple options, each carrying pros, cons, risks, alternatives, and consequences. Tracks decision lifecycle from Draft through Resolved.
5. **Constraint Analyzer** — Detects and manages constraints following The Goal (TOC) philosophy. Supports 4 severity levels and 6 lifecycle stages per PHI-003.000 COM-LC.
6. **Value Analyzer** — Creates value assessments across 8 dimensions (PHI-002.000 VD-001..VD-008). Computes top value dimensions by average confidence.
7. **Recommendation Composer** — Composes recommendations through the mandatory 6-stage chain (Understanding → Value → Constraint → Optimization → Explanation → Recommendation). Supports TTL-based expiration and max-recommendation eviction.
8. **Knowledge Synthesizer** — Maintains a personal knowledge graph with typed nodes (9 types) and typed edges (10 types). Supports graph traversal and text search.
9. **Conversation Interpreter** — Classifies conversation intent (10 intent types), extracts entities, and suggests contextual actions. Falls back to keyword-based detection when AI provider is unavailable.
10. **Habit Insights** — Detects habits with strength classification (4 levels) and direction (Positive, Negative, Neutral). Supports observation recording to strengthen confidence.
11. **Priority Optimizer** — Calculates multi-factor priority scores (8 factors: deadline, importance, urgency, energy, context, dependencies, risk, value). Supports batch calculation and ranking.
12. **Personal Dashboard** — Generates unified dashboards aggregating goals, constraints, recommendations, and insights. Supports custom insight cards.
13. **Metrics Runtime** — Accumulates counters, gauges, and time-series data. Computes trends (improving/declining/stable) over configurable windows.
14. **Trace Runtime** — Provides distributed tracing with spans, child spans, and events. Tracks active spans and computes average duration per subsystem.
15. **Personal Intelligence Pack Runtime** — Orchestrator that wires all 14 subsystems above, manages the pack lifecycle FSM (Created → Initializing → Active → Onboarding → Ready → Suspended → Disabled), and provides the First Intelligence Experience.
