# SRC-010.000 — Desktop Foundation Manifest

## 1. Общие сведения

**Идентификатор:** TASK-AIS-004B
**Версия:** 1.0.0
**Конфигурация:** Desktop Application Foundation

## 2. Структура Desktop Runtime

### 2.1. Desktop Runtime (Оркестратор)
Путь: `src/desktop/desktop-runtime/`

Координирует все 14 подсистемы. Обеспечивает:
- Последовательная инициализация всех подсистем
- Управление состоянием (Uninitialized → Initializing → Ready → Running → Stopping → Stopped)
- Предоставление доступа к подсистемам через `getSubsystem<T>(name: string): T`

Зависимости: Все подсистемы Desktop Foundation.

### 2.2. Подсистемы

| # | Подсистема | Описание | Путь |
|---|------------|-------------|------|
| 1 | Window Manager | Управление окнами: CRUD, фокусировка, z-ordering, layout | `desktop/window-manager/` |
| 2 | Navigation Runtime | Навигация между экранами: реестрация, история, параметры маршрутов | `desktop/navigation-runtime/` |
| 3 | Workspace Runtime | Рабочие пространства: CRUD, переключение, архивация | `desktop/workspace-runtime/` |
| 4 | Project Runtime | Управление проектами: CRUD, теги, настройки | `desktop/project-runtime/` |
| 5 | Session Runtime | Управление сессиями: CRUD, привязка к Identity | `desktop/session-runtime/` |
| 6 | Local Storage Runtime | Ключ-значное хранилище: get/set/has/delete, quotas | `desktop/local-storage-runtime/` |
| 7 | Theme Runtime | Управление темами: CRUD, пресеты | `desktop/theme-runtime/` |
| 8 | Notification Runtime | Уведомления: CRUD, непрочитанные, очередь | `desktop/notification-runtime/` |
| 9 | Command Palette | Палитра команд: регистрация, поиск, выполнение | `desktop/command-palette/` |
| 10 | Search Runtime | Полнотекстовый поиск: индексация, коллекции | `desktop/search-runtime/` |
| 11 | Startup Runtime | Последовательность запуска: шаги, тайминг | `desktop/startup-runtime/` |
| 12 | Settings Runtime | Настройки: CRUD, импорт/экспорт, дефолты | `desktop/settings-runtime/` |
| 13 | Diagnostics Runtime | Диагности: health checks, метрики, логирование | `desktop/diagnostics-runtime/` |
| 14 | Crash Recovery Runtime | Восстановление после сбоев: снимки, журнал | `desktop/crash-recovery-runtime/` |

### 2.3. Общие типы
- `DesktopConfig` — конфигурация Desktop приложения
- `WindowId`, `WorkspaceId`, `ProjectId`, `SessionId`, `ThemeId`, etc. — брендированные идентификаторы
- `DesktopState` — enum состояний оркестратора
- `WindowBounds`, `WindowInfo`, `CreateWindowOptions` — типы окон
- `ScreenDefinition`, `NavigationEntry`, `NavigationState` — типы навигации
- `Workspace`, `CreateWorkspaceOptions` — типы рабочих пространств
- `ProjectEntity`, `SessionEntity`, `ThemeEntity` — сущности
- `ThemePreset` — предустановки тем

### 2.5. Зависимости

- Все подсистемы реализуют интерфейс `Service` из Core
- Event Bus используется через публичный API (не напрямую)
- Dependency Rules соблюдены: Desktop → Core → Domain
- Инверсия зависимостей: Desktop зависит от Core, Core от Domain
